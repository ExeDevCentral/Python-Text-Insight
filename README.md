# Python Text Insight

Un potente analizador de texto desarrollado en Python que procesa entradas de usuario para extraer estadísticas clave.

## Descripción

Este proyecto pone en práctica el manejo de estructuras de datos (listas, diccionarios, tuplas) y métodos avanzados de manipulación de strings.

El programa solicita al usuario un texto y tres letras, y luego devuelve:
1.  La cantidad de veces que aparece cada letra.
2.  La cantidad de palabras en el texto.
3.  La primera y última letra del texto.
4.  El texto con el orden de las palabras invertido.
5.  Si la palabra "Python" se encuentra en el texto.

## Ejecución

```bash
python text_analyzer.py
```
